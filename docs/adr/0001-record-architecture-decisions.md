# 1. Record architecture decisions

Date: 2026-10-23 · Status: accepted

## Context

Decisions about structure and tools get made once and questioned many times. Without a record, the reasons are lost
and the same debates repeat.

## Decision

We keep short Architecture Decision Records in `docs/adr/`, numbered in order, each with Context, Decision and
Consequences. A decision is changed by a new ADR that supersedes the old one, never by editing history.

## Consequences

Anyone (including a future us) can see why the code is the way it is. Writing one takes ten minutes.
